## 执行、校验与日志

LocalServer RTX 5070（12,227 MiB）；JAX 0.7.2、NumPy 2.5.3、CPU Torch 2.8.0+cpu。复用既有依赖，无新包安装；`attention=manual`、`batch=64`、`action_chunk=2048`，模型、默认配置及训练算法不变。

独立 GPU 预算为 60 分钟，包含预检。实际单 GPU 进程墙钟 **378.263 秒（6.30 分钟）**，退出码 0，未超时；新增训练更新和训练 GPU 消耗均为 **0**。该时间包含 CPU 等待，不是 CUDA 内核忙碌时间。结束后 GPU 计算进程列表为空。

完整状态通过 Store、manifest、`check_array_state` 与 replay 恢复验证；20,000 更新等于 Adam.step。原始 2,000/20,000 训练归档 SHA256 未变。预检重复结果完全一致，所有预检和正式推理前后的候选及对手参数均未变化。11 项相关测试通过，统计自检通过，Mac 与服务器复算的统计 JSON 字节一致；从 Drive 读回归档恢复到独立目录后，复核脚本再次通过。

20,000 状态的 replay 有 65,536 条，三角色计数为 22,626 / 21,670 / 21,240；最终驻留年龄 p0/p50/p95/p100 为 4/72/128/144 次更新。日志 nonfinite_steps 总数为 0，grad_norm 的 p0/p50/p95/p100 为 0.288/21.039/28.842/42.131，均有限。累计训练样本使用量/完整采样量约为 0.499994。日志未记录逐次抽样 replay age，驻留年龄不能替代训练期间的实际抽样年龄；这些观察不构成因果解释。旧吞吐分析器终点提示原样保留，未重训或改写历史结果。

## 限制与下一项假设

名义 95% CI 未对多指标、两对手、两比较整体校正，也不包含训练 seed 总体的不确定性。不能声明跨 seed 稳定改善；latest 的 Balanced 绝对胜率仍仅 12.925%/15.100%，不推断人类竞技水平。来源未认证的固定权重、哈希冻结而非服务端 WORM，以及基础镜像可用性限制均保留。

下一项唯一假设：保持架构与配方不变，另一个独立训练 seed 能否复现 20,000 latest 相对 2,000 latest 在两个对手上的 Balanced 改善。本轮已停止，未启动该训练或任何续训。
