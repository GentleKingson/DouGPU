# seed45 八小时复现与三 seed 最终决策

本文为发布版报告；原始证据保存在 Git 忽略目录中，未随仓库发布；获取与校验方式见[证据说明](../experiment-evidence.zh-CN.md)。

日期：2026-10-03，Asia/Hong_Kong。

## 最终结论

**seed45 为 INCONCLUSIVE，五项门槛通过 4 项。按执行前冻结的规则，结束预算扩张，维持 6h 训练预算决策，进入角色方差调查。** 不进入 12h，不追加第四 seed，不补抽留出，不扩大本轮牌局，也不选中间 checkpoint。

WP Balanced 再次未通过改善门槛：8h 减 6h 为 +0.0833pp，单侧 99% 下界 -0.5000pp。WP 农民点差 -0.1833pp，仍通过 -3pp 非劣门槛；不能说 WP 农民 gate 失败。ADP 地主点差 -0.1500pp，触发额外方向警示，其 99% 下界 -0.9584pp 虽勉强高于 -1pp 风险线，也不支持有利结论。

三个 seed 最终为 **一次 PASS、两次 INCONCLUSIVE**，不是“两次 PASS 的可复现候选”。结果没有证明 8h 普遍无效或显著退化，但没有达到事前要求的可靠跨 seed 收益，不能据平均正点差继续扩大预算。这里的 6h 是实验预算决策，未把项目用于单次会话的 `max_hours=2` 擅自改为 6。

## 评估与 seed45 结果

执行前扫描所有已有 report JSON 与 checkpoint metadata，冻结新 seeds `986001–986048`，与 `eval_seed=900001` 及历史 selection/validation/holdout seeds 隔离。48 chunks，每块 250 副，共 12000 个独立发牌单位。6h、8h 对 WP、ADP 的四组共用相同有序牌，每副交换地主与农民团队，共 96000 局，不能当作 96000 个独立样本。

WP/ADP 六份角色权重、严格安全加载、模型和评估语义与前轮一致。权重为冻结用户提供文件，不宣称重新独立认证官方发布身份。保存全部 192 个 chunk 的原始 paired outcomes、ordered-deal hash 与对手/策略/协议身份；生产审计重建牌序并从原始 outcomes 重算统计。

继续使用 2000 次完整发牌对 bootstrap。五项 gate 为单侧 99% 下界：WP Balanced > 0pp；WP/ADP 地主 >= -1pp；WP/ADP 农民 >= -3pp。方向检查仍要求两个 Balanced 点差为正、两个地主点差非负。下面 95% CI 是逐项名义区间，非全程多重/序贯同时区间；五项近似 Bonferroni 解释仅针对该次固定观察。

绝对胜率单位为百分比；差值与区间单位为百分点 pp。
