# 角色学习差异：只读端点机制分析

日期：2026-10-08。状态：**COMPLETE / INCONCLUSIVE，记录缺口并停止**。发现局部角色梯度方向相反的 batch，但未识别可解释地主胜率差异的持续机制，不设计或启动后续训练实验。Checkpoint Selection 维持 **CLOSED / NO_DECISION**，默认策略不变，最终留出未使用。

## 范围与方法

复用既有 2,000 / 20,000 更新完整 checkpoint、训练日志和 replay。每个端点克隆存档 RNG，固定调用 `Replay.sample` 四次，每次 256 行，继续使用 `group_history`。共 2,048 次 replay 行抽取，允许重复，不是新增牌局，也不是 2,048 个独立样本。协议在运行前冻结，无追加或换样。

直接对原 `sample_losses` 做 `jax.value_and_grad`：分别测量实际加权总损失，以及作为诊断分解的 Q-only 损失。角色 mask 将原权重乘以 `3 * (role == r)`，保留相同的原 batch 和各角色原权重；三角色结果平均应恢复整体目标。梯度取原始、裁剪前数值，不执行梯度裁剪、Adam 或参数更新。保留完整原 ModelConfig / TrainConfig，包括 BF16、cuDNN attention、learner_remat、NTP / Belief 权重及 history grouping。

共享 Transformer 组含 embedding、全部 block 和 final_norm；共享 Q 隐藏层组含 state1/state2/q1/q2。排除独立 Q 输出列及辅助输出头，避免把互不共享的参数误当成主干冲突。实际总损失与 Q-only 结果均保存在原始 JSON。

LocalServer RTX 5070 上耗时 **16.291 秒**，限额 600 秒，退出成功。仅前向及反向诊断，**optimizer steps = 0，新牌局 = 0**。未调用 `make_train_step`，未使用选优或最后留出牌。

## 代码与数据发现

1. 三角色共享 Transformer 和 Q 隐藏层，但已经有独立的三个 Q 输出列，不能称为完全共用一个 Q 输出。
2. `Replay.sample` 按角色分层，每个 batch 为地主 86 行、下家 85 行、上家 85 行；权重使各角色总贡献均为 1/3。不能从 replay 原始行数差推断训练角色权重不足。
3. 三角色目标都为 ±1，两农民使用相同的团队胜负目标。replay 行按状态保存，行数和正目标比例不是完整局胜率。
4. 历史训练日志记录整体 loss、q_loss、ntp_loss、belief_loss、grad_norm，没有逐角色损失、梯度向量或每次抽样的物理索引/年龄。端点 replay 和 RNG 无法恢复已被覆盖的历史 batch；以下结果是重新计算的端点诊断，不是过去的实际训练梯度。

## 角色损失

下表为每端点四个固定 batch 的平均原始损失分量，辅助分量尚未乘目标权重。角色为地主 / 地主下家 / 地主上家。

| 端点 | 角色 | Q MSE | NTP | Belief |
|---|---|---:|---:|---:|
| 2k | 地主 | 0.553675 | 1.632038 | 0.036905 |
| 2k | 下家 | 0.485147 | 1.590531 | 0.029930 |
| 2k | 上家 | 0.487624 | 1.595052 | 0.030840 |
| 20k | 地主 | 0.446495 | 1.179156 | 0.030991 |
| 20k | 下家 | 0.541273 | 1.146313 | 0.026597 |
| 20k | 上家 | 0.500505 | 1.141553 | 0.026221 |

20k 这四个 batch 中地主平均 Q MSE 较低，并不支持“地主持续有更高拟合误差”的简单解释。地主辅助损失略高，但角色输入分布不同，不能据此推断学习慢。**两个端点使用各自 replay，不能把表中端点差当成同一数据分布上的学习曲线；Q MSE 也不能直接替代棋力。**

既有独立强对手评估中，2k→20k latest 的地主点差为 WP +6.50pp、ADP +6.75pp，均有正向区间；此次选优比较的是 20k latest 与 8.1k champion。二者比较对象不同，“latest 对 champion 的收益偏向农民”不能推出“地主整个训练过程没有进步”。此处引用旧报告，未重新评估。

## 共享层梯度

以下为实际总目标，四个固定 batch 中的负 cosine 次数与范围。负值只表示所测原始梯度在该参数组的局部一阶方向相反。

| 端点 | 参数组 | 地主–下家 | 地主–上家 | 下家–上家 |
|---|---|---|---|---|
| 2k | Transformer | 1/4；[−0.106, +0.212] | 1/4；[−0.009, +0.164] | 0/4；[+0.049, +0.133] |
| 20k | Transformer | 1/4；[−0.014, +0.071] | 2/4；[−0.120, +0.155] | 1/4；[−0.049, +0.150] |
| 2k | 共享 Q 隐藏层 | 2/4；[−0.485, +0.559] | 1/4；[−0.067, +0.404] | 2/4；[−0.112, +0.659] |

Q-only 的 cosine 与总目标接近，但这不构成移除辅助任务的依据。负值也出现在两个农民之间，方向随 batch 与参数组改变。四批结果既不能确认持续的地主特异冲突，也不能排除它；均未对实际 Adam 预条件更新、长期梯度累计或棋力因果效应作出推断。接近零的 cosine 尤其受 BF16 舍入与样本变动影响，不应解释其符号。

## 校验、缺口和停止

- 每个端点均验证角色损失分解恢复整体目标。BF16 下分角色梯度平均与整体梯度的相对误差分别为 0.898% / 0.878%，小于事前脚本固定的 3% 容差；这不是精确浮点相等声明。
- cosine 正反向及零范数 assert 自检通过；所有测量梯度、loss 有限；每个 batch 的角色数量核对通过；完整参数逐数组未改变，checkpoint SHA256 前后相同，Adam.step 保持 2,000 / 20,000。
- 116 个评估源码文件与原冻结身份一致，10 个原始归档/对手输入文件 SHA256 仍一致。原始模型、日志和 replay 挂载只读。
- 缺失：历史逐角色 loss/梯度、实际抽样索引及年龄、完整历史 replay/actor 状态、跨 seed 和受控因果对照。因此无法回答“历史上是否持续冲突并导致地主进展滞后”。不补采、不延长诊断、不启动训练，也不据此调整架构、角色权重或风险线。
